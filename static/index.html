ClaroUnify Hub

Orquestrador conversacional omnicanal — MVP funcional

Visão do projeto

MVP 100% funcional do orquestrador conversacional descrito no Documento de Visão (Sprint 1 e 2). Demonstra o fluxo completo: canais → autenticação silenciosa → NLU → roteador de agentes → agentes especializados → backends → handoff → dashboard de KPIs.

Áreas da demonstração

  • Sou Cliente — escolha de canal (Site ou WhatsApp), chat unificado, migração entre canais sem perder contexto e campanha proativa.
  • Painel Claro (interno) — Dashboard Admin com KPIs ao vivo, fila de Handoff com transcrição mascarada (LGPD) e Iniciar Contato individual ou em massa.

Stack e arquitetura

FastAPI SQLite Ollama / Qwen3 4B Chart.js HTML / CSS / JS

Componentes reais e funcionais: roteador de agentes, handoff, KPIs, LGPD e continuidade entre canais. Mocks conscientes: WhatsApp simulado na UI, CRM/BSS em SQLite, eventos em memória.
